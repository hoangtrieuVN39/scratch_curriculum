Đúng hay Sai? 👍👎

Thầy/Cô đọc từng câu, cả lớp giơ ngón cái lên (Đúng) hoặc xuống (Sai) — click từng câu để mở đáp án ↓

1
"My Block (Khối của tôi) giúp gom nhiều khối lệnh thành một khối có tên riêng."
→ Đúng! Giúp code gọn gàng, dễ đọc và dùng lại nhiều lần.
2
"Khối `định nghĩa` (define) là nơi em gọi My Block để chạy."
→ Sai! Khối định nghĩa là nơi viết ruột code; khối mang tên riêng mới là nơi gọi ra chạy.
3
"Khi debug (tìm sửa lỗi), bước đầu tiên nên làm là quan sát kỹ triệu chứng lỗi."
→ Đúng! Quan sát hiện tượng bất thường giúp xác định chính xác vị trí cần kiểm tra.
4
"Thêm khối `nói` (say test) tạm thời vào code là một cách debug hợp lệ."
→ Đúng! Khối nói giúp kiểm tra xem Scratch có thực sự chạy đến dòng lệnh đó không.
5
"Một game hay không cần màn Start hay Game Over, chỉ cần chạy mãi mãi."
→ Sai! Game hấp dẫn cần có luồng hoàn chỉnh: Bắt đầu (Start) ➡️ Gameplay ➡️ Kết thúc (Game Over/Win) ➡️ Chơi lại (Reset).

Trạm kỹ năng Tháng 3 — Logic nâng cao ⚡

Hôm nay là buổi tổng kết lớn nhất Tháng 3! Em sẽ kết hợp toàn bộ vũ khí lập trình đã học để tạo ra một Game mini hoàn chỉnh mang dấu ấn của riêng mình! 🏆
🎲 Biến & Phép toán Quản lý điểm, thời gian, mạng; phép so sánh điều kiện & lấy ngẫu nhiên.
📡 Thông báo (Broadcast) Điều phối các màn chơi mượt mà: nhận tin start để chơi, phát tin game over khi kết thúc.
👥 Bản sao (Clone) Tạo mưa rơi, sao rơi, bóng bay liên tục bằng clone và luôn xóa clone khi chạm đáy.
🧩 My Blocks & Debug Gom code thành các khối gọn gàng (reset game, tăng điểm) và tư duy bác sĩ sửa lỗi 6 bước.
✍️ Luyện tập tại lớp (15–20 phút)

LT1 Gom code thành My Block 🧩

Mở project cũ (game bắt sao hoặc game tuần trước) và refactor (gom code): tạo ít nhất 2 My Blocks (ví dụ reset game và tăng điểm), thay thế các đoạn code lặp lại.

Yêu cầu cần đạt

  • Tạo ít nhất 2 My Blocks có tên rõ ràng (ví dụ: reset game, tăng điểm).
  • Mỗi My Block có ≥ 2 khối lệnh bên trong định nghĩa.
  • Game vẫn chạy chính xác như cũ sau khi gom code.
  • Lưu project với tên: LT1-refactor-my-block.
🔄
Đổi máy 2 phút: Nhờ bạn bên cạnh bắt lỗi giúp xem sau khi gom My Block, game có còn chạy trơn tru không!

A1 Refactor My Block 🧩

Project game của em đang cồng kềnh với nhiều đoạn lệnh lặp đi lặp lại. Đã đến lúc dọn dẹp sạch sẽ: gom thành 3 My Blocks chuyên nghiệp!

Yêu cầu bắt buộc

  • Tạo đủ 3 My Blocks: reset game, tăng điểm, game over.
  • Mỗi khối có ≥ 2 lệnh bên trong phần định nghĩa.
  • Thay thế code cũ bằng các khối gọi tương ứng.
  • Chạy thử kiểm tra toàn bộ tính năng và lưu project.

✨ Thử thêm (Thách thức)

Thêm tham số đầu vào cho khối tăng điểm (số điểm) để 1 khối duy nhất vừa cộng +1 điểm (táo thường) vừa cộng +5 điểm (kim cương hiếm)!

A2 My Block gameOver 🛑

Mọi game đều cần kết thúc chuẩn xác và đẹp mắt! Em tạo My Block game over để dừng game trong nhiều tình huống khác nhau.

Yêu cầu bắt buộc

  • Tạo My Block game over có ≥ 3 khối lệnh bên trong: nói thông báo + phát tin game over + dừng lại tất cả.
  • Gọi khối game over ở ít nhất 2 tình huống (ví dụ: khi hết 30s VÀ khi hết 3 mạng).
  • Kết hợp với khối reset game khi bắt đầu ván mới.

✨ Thử thêm

Thêm âm thanh tiếng nổ (Explosion) và tạo biến điểm cao nhất để khối game over tự so sánh cập nhật kỷ lục mới!

Gợi ý cấu trúc khối

phát tin [hiện bảng điểm]
dừng lại [tất cả]

Khi hết giờ hoặc hết mạng:

nếu <(thời gian) = (0)> thì
game over

B1 Sửa 3 project lỗi (Bác sĩ Scratch) 🔧

Em trở thành Bác sĩ lập trình Scratch hôm nay — khám và chữa khỏi hoàn toàn cho cả 3 project mẫu bị sự cố!

1
Project 1 ("Bắt sao"): Cờ xanh không reset điểm ➡️ thêm đặt điểm thành 0; Cat không di chuyển ➡️ bọc trong liên tục; Chạm sao không tăng điểm ➡️ sửa lại đúng tên biến.
2

3
Project 3 ("Mưa clone"): Không thấy mưa ➡️ chuyển code rơi sang khi tôi bắt đầu là một bản sao; Game giật lag sau 30s ➡️ thêm xóa bản sao này khi chạm đáy; Mưa rơi giữa màn hình ➡️ thêm đi tới y: 180.

Ghi chú: Viết ngắn gọn những chỗ em đã sửa vào sổ tay hoặc comment Scratch để luyện tư duy debug có hệ thống!

B2 Sửa project lỗi #4 (Game bắt táo) 🍎🔧

Ca bệnh đặc biệt trong project BT-loi-4.sb3! Đọc bảng triệu chứng, tìm nguyên nhân cốt lõi và chữa trị dứt điểm.

Vấn đề Triệu chứng lỗi Nguyên nhân & Cách sửa
Lỗi 1 Bấm nút Start, game không bắt đầu (nhân vật đứng yên) Sai tên tin nhắn: Nút phát start nhưng nhân vật chờ Start ➡️ Sửa cho giống hệt nhau từng chữ.
Lỗi 2 Chạm vào táo, điểm không tăng My Block tăng điểm đã có định nghĩa nhưng ở phần chạm táo quên gọi khối ➡️ Kéo khối tăng điểm vào trong nếu đang chạm.
Lỗi 3 Hết 30 giây, game không dừng lại (vẫn chơi tiếp) Trong khối định nghĩa game over bị thiếu lệnh dừng lại tất cả ➡️ Kéo bổ sung vào cuối định nghĩa.
🎯 Yêu cầu: Sửa hết 3 lỗi ➡️ Chơi thử 2 lần ➡️ Lưu project tên LT-sua-loi-4.

C1 Game mini hoàn chỉnh 🎮🌟

Tác phẩm đỉnh cao Tháng 3! Em tự làm một Game mini hoàn chỉnh kết hợp tất cả kiến thức đã học để biểu diễn trong buổi Showcase!

Các yếu tố bắt buộc có trong game

  • 🔘 Màn Start: Nút Play phát tin start để bắt đầu.
  • 🎮 Gameplay: Điều khiển nhân vật bắt vật phẩm hoặc né chướng ngại vật (dùng clone hoặc nhiều sprite).
  • 🏆 Biến số: Có biến điểm hiển thị và cập nhật liên tục.
  • 🧩 My Block: Có ít nhất 1 My Block (ví dụ reset game).
  • 🛑 Game Over: Kết thúc rõ ràng bằng thông báo và dừng lại tất cả.
  • 🔊 Âm thanh: Có tiếng khi ăn điểm và tiếng khi thua.

🗺️ Storyboard 3 bước chuẩn

1. Trạng thái Chờ: Nút Start hiện, nhân vật ẩn, điểm = 0.

2. Trạng thái Chơi: Nhận tin start ➡️ Nút Start ẩn ➡️ Clone xuất hiện liên tục ➡️ Bắt đầu tính điểm và đếm giờ.

3. Trạng thái Kết thúc: Hết giờ/hết mạng ➡️ Gọi game over ➡️ Báo tổng điểm ➡️ Dừng game.

✨ Thử thêm

Thêm màn Thắng khi đạt mốc 15 điểm, hoặc thêm biến mạng (3 mạng)!

C2 Remix game tuần 22 lên bản Pro 🔄✨

Các nâng cấp cần thêm vào
