Clone (Nhân bản)

Lập trình Scratch — Tháng 3 · Logic nâng cao

📅 Tuần 11 📘 Buổi 21 — Học 🎯 7–10 tuổi

Nhấn → hoặc Space để bắt đầu

🎬 Mục tiêu & Khởi động (10 phút)

Hôm nay em học gì? & Trò chơi 👥

Hôm nay em học clone (nhân bản) — tạo nhiều bản sao của một sprite mà không cần kéo thủ công! Em sẽ làm hiệu ứng mưa, sao rơi, bong bóng bay 🌧️⭐

Trò chơi "Một người, nhiều bản sao"

  • Mời 1 bạn làm bản gốc — đứng yên giơ tay lên.
  • Mời 3–4 bạn khác đứng phía sau làm bản sao bắt chước y hệt tư thế bạn đầu tiên.
❓
Hỏi cả lớp: "Những bạn phía sau có phải 'y hệt' bạn đầu không? Nếu bạn đầu đổi tư thế, các bạn phía sau có tự đổi theo không?"
👉 Dẫn vào khái niệm Clone: bản sao giống hệt hình dạng ban đầu nhưng có vị trí và số phận riêng!
💡 Kiến thức mới (20 phút)

1. Clone là gì? 👥

Clone = bản sao của sprite gốc — giống hệt hình, âm thanh, nhưng có vị trí riêng.
Sprite gốc gọi là bản gốc; các bản sao gọi là clone. Một sprite có thể tạo rất nhiều clone!

Các khối lệnh quan trọng hôm nay

create clone of [myself] Tạo một bản sao của chính sprite này (hoặc sprite khác).
when I start as a clone Đoạn code chỉ chạy riêng khi clone vừa được tạo.
delete this clone Xóa clone hiện tại khi hoàn thành nhiệm vụ (không xóa bản gốc).
⚠️ Quy tắc & Thuật toán

Quy tắc vàng & Mẫu mưa rơi 🌧️

Quy tắc quan trọng cần nhớ ⚠️

  • Code trên bản gốc (when green flag clicked) KHÁC với code trên clone (when I start as a clone).
  • Clone không chạy lại code when green flag clicked.
  • Luôn delete this clone khi clone ra khỏi màn hình — nếu không, clone tích tụ làm game chậm dần (lag)!
Vì sao quan trọng? Clone giúp em viết code 1 lần cho bản gốc, rồi Scratch tự nhân bản ra bao nhiêu tùy ý — nền tảng cho quái vật, vật phẩm, hiệu ứng thời tiết!

Mẫu thuật toán mưa / sao rơi 🌧️

when green flag clicked / khi bấm cờ xanh (Bản gốc)
hide / ẩn bản gốc
forever / lặp mãi
create clone of [myself] / tạo bản sao của chính tôi
wait 0.3 seconds / chờ 0.3 giây
when I start as a clone / khi tôi bắt đầu là một bản sao (Clone)
show / hiện bản sao
go to x: (pick random -240 to 240) y: (180) / đi tới x ngẫu nhiên, y: 180
repeat until <y position < -180> / lặp lại cho đến khi y < -180
change y by -5 / thay đổi y một lượng -5
delete this clone / xóa bản sao này
🔍 Ví dụ mẫu

Ví dụ mẫu & Trắc nghiệm dự đoán 🎲

Ví dụ mẫu 1 — Một giọt mưa rơi

Bản gốc tạo 1 clone. Clone tự pick random vị trí x phía trên và rơi xuống chạm đáy rồi xóa.

when green flag clicked / khi bấm cờ xanh
create clone of [myself] / tạo bản sao
when I start as a clone / khi tôi bắt đầu là bản sao
go to x: (pick random -240 to 240) y: (180) / vị trí ngẫu nhiên
repeat until <y position < -180> / lặp lại đến khi chạm đáy
change y by -8 / rơi xuống
delete this clone / xóa bản sao

Ví dụ mẫu 2 — Ba giọt mưa độc lập

Bản gốc gọi 3 khối create clone liên tiếp. Ba giọt mưa xuất hiện ở 3 vị trí x khác nhau vì mỗi clone tự chạy pick random độc lập!

💡
Dù dùng chung 1 đoạn code when I start as a clone, mỗi clone vẫn tự "bốc" vị trí riêng, không copy kết quả của nhau.
❓
Em đoán xem? Nếu bản gốc tạo clone 3 lần liên tiếp (không có wait), 3 clone sẽ rơi ở cùng 1 vị trí x hay 3 vị trí khác nhau?
→ 3 vị trí khác nhau! Vì mỗi clone khi sinh ra đều tự thực hiện lệnh pick random của riêng mình.
✍️ Thực hành (15 phút)

TH1 Mưa đơn giản (clone liên tục) 🌧️

Em làm hiệu ứng mưa: bản gốc liên tục tạo clone, mỗi clone xuất hiện ở vị trí ngẫu nhiên phía trên và rơi xuống, rồi tự xóa khi chạm đáy màn hình.

Gợi ý từng bước

  1. Tạo project mới, chọn sprite Dot (hoặc vẽ giọt nước) → thu nhỏ 30–50%.
  2. Bản gốc: hide → forever → create clone → wait 0.2 secs.
  3. Clone: show → go to x: (pick random -240 to 240) y: (180).
  4. Cho clone repeat until <y position < -180> → change y by -6.
  5. Gắn delete this clone ở cuối chuỗi.
  6. Lưu project với tên TH1-mua-don-gian.

create clone of [myself] / tạo 1 bản sao
wait 0.2 seconds / chờ 0.2 giây
when I start as a clone / khi tôi bắt đầu là bản sao
show / hiện bản sao
go to x: (pick random -240 to 240) y: (180) / x ngẫu nhiên, y 180
repeat until <y position < -180> / lặp lại đến khi chạm đáy

Người dẫn đầu và các bản sao 🏃

Cùng vận động cơ thể để hiểu rõ hơn cách hoạt động của Clone nhé!
🧍‍♂️ 🧍‍♀️ 🧍‍♂️ 🧍‍♀️
  • Bản gốc: Một bạn đứng đầu hàng thực hiện các động tác đơn giản (giơ tay, xoay người, vỗ tay...).
  • Clone: Các bạn phía sau xếp hàng copy lại đúng động tác của bạn trước mình với độ trễ 0.5 giây.

✍️ Thực hành (15 phút)

TH2 Clone khi nhấn phím 🎈

Em làm game: mỗi lần nhấn phím Space, tạo một clone bay lên từ bên dưới — giống như thả bong bóng bay!

Gợi ý từng bước

  1. Chọn sprite Balloon hoặc Star, đặt tên Bong bóng.
  2. Bản gốc: when green flag clicked → show → go to x: 0 y: -150.
  3. Gắn sự kiện: when space key pressed → create clone of [myself].
  4. Clone: when I start as a clone → go to x: (pick random -200 to 200) y: -150.
  5. Lặp repeat until <y position > 180> → change y by 4 → delete this clone.
  6. Lưu project với tên TH2-clone-phim.

create clone of [myself] / tạo 1 bản sao
when I start as a clone / khi tôi bắt đầu là bản sao
go to x: (pick random -200 to 200) y: -150 / x ngẫu nhiên ở dưới
repeat until <y position > 180> / lặp đến khi lên khỏi mép trên

delete this clone / xóa bản sao này

🕵️ Trò chơi đoán số clone

Bạn A nhấn Space một số lần bí mật (ví dụ 4 lần). Bạn B nhìn màn hình đếm số bong bóng đang bay và đoán xem bạn A đã bấm Space mấy lần!

⚡ Kiểm tra Lag

Thử nhấn Space liên tiếp thật nhanh (5–6 lần trong 2 giây). Quan sát xem game có bị chậm/lag không? Nếu có, lý do là gì?

💡 Mẹo hay

Bí kíp làm việc với Clone 💡

👻
Ẩn bản gốc: Bản gốc nên hide nếu em chỉ muốn thấy các clone xuất hiện trên màn hình (như mưa).
⚠️
Tránh giật lag: Nếu game chậm dần, kiểm tra xem em đã gắn delete this clone chưa! Clone tích tụ không xóa sẽ gây đơ/lag game.
⏱️
Mật độ clone: Lệnh wait giữa mỗi lần create clone quyết định mưa dày hay thưa.
🎨
Kế thừa: Clone tự động copy trang phục (costume) và âm thanh từ bản gốc tại thời điểm được sinh ra.

Trạm tiếp sức trả lời 🏁

Click vào từng câu hỏi bên dưới để kiểm tra đáp án cùng cả lớp ↓

1
Clone khác sprite gốc thế nào?
→ Clone là bản sao giống hình/âm thanh nhưng có vị trí và hành vi độc lập.
2
Khối when I start as a clone dùng để làm gì?

→ Bọc create clone of myself và wait trong vòng lặp forever của bản gốc.
5
create clone of myself nên đặt ở bản gốc hay clone?
→ Đặt ở bản gốc (hoặc sự kiện bấm phím/click) để quản lý việc sinh ra clone.
