Đúng hay Sai?

Cô đọc từng câu, cả lớp giơ ngón cái lên (Đúng) hoặc xuống (Sai) — rồi click để xem đáp án ↓

1
"Clone có hình dạng khác hoàn toàn so với bản gốc."
→ Sai — clone giống hệt hình dạng, âm thanh của bản gốc.
2
"when I start as a clone chạy trên bản gốc."
→ Sai — chỉ chạy trên clone mới tạo, không chạy trên bản gốc.
3
"Không xóa clone thì game có thể bị chậm dần."
→ Đúng.
4
"Một sprite chỉ được tạo tối đa 1 clone."
→ Sai — có thể tạo rất nhiều clone cùng lúc.
5
"Clone kế thừa costume của bản gốc tại thời điểm nó được tạo ra."
→ Đúng.

Nhớ lại Clone

Hôm nay em luyện lại clone ngay tại lớp, rồi tự chọn 1 bài mở rộng để làm mưa rơi, bong bóng bay hoặc game bắt đồ rơi có điểm!
👥 🌧️ ⭐ 🗑️
👥 create clone of myself Tạo 1 bản sao giống hệt hình, âm thanh của bản gốc
🆕 when I start as a clone Code chạy trên mỗi clone mới, không chạy trên bản gốc
🗑️ delete this clone Xóa clone — luôn xóa khi không cần nữa, không thì game chậm dần!
✍️ Luyện tập tại lớp

LT1 Xóa clone đúng cách 🗑️

Em luyện làm hiệu ứng nhiều hạt rơi (mưa, tuyết, lá...) và đảm bảo mỗi clone tự xóa khi chạm đáy màn hình — game không bị chậm!

Yêu cầu

  • Bản gốc tạo clone liên tục (forever + wait)
  • Clone rơi từ trên xuống
  • Bắt buộc có delete this clone khi clone ra khỏi màn hình
🔄
Đổi máy 2 phút: chơi thử project của bạn 1 phút xem có bị chậm dần không (dấu hiệu quên xóa clone).

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
hide / ẩn bản gốc
forever / lặp mãi
create clone of myself / tạo 1 clone
wait 0.3 seconds / chờ 0.3 giây
when I start as a clone / khi 1 clone mới xuất hiện
show / hiện clone
go to x: pick random y: 180 / vị trí random trên cùng
forever / lặp mãi
change y by -5 / rơi xuống
if <y < -180> then / nếu ra khỏi màn hình
delete this clone / xóa clone này
✍️ Luyện tập tại lớp

LT2 Sao rơi ⭐

Em luyện làm sao rơi từ trên xuống. Nhân vật chính bắt sao (chạm clone) để +1 điểm. Sao chạm đáy thì biến mất.

Yêu cầu

  • Sao (clone) rơi liên tục từ trên
  • Nhân vật điều khiển 4 phím
  • Chạm sao → +1 điểm + delete this clone
  • Biến điểm hiển thị trên Stage
🩹
Sao không xóa? Kiểm tra delete this clone nằm trong code clone, không phải bản gốc.

show / hiện sao

Giáo viên demo nhanh bài A1 "Mưa emoji" — chỉ rõ cách đổi emoji và backdrop cho hợp không khí. Sau đó em chọn 1 mức A, B hoặc C, rồi chọn 1 trong 2 bài của mức đó. Mỗi bài có 1 slide riêng — bấm chấm phía trên để tới bài em chọn.

A1 Mưa emoji 🌧️

Em muốn biến Stage thành một buổi chiều mưa buồn nhẹ nhàng — em làm mưa emoji (💧, ❄️, 🍂...) rơi liên tục. Đổi backdrop thành bầu trời xám cho đẹp!

Yêu cầu

  • Clone liên tục; emoji rơi từ trên

Random 2–3 emoji khác nhau (đổi costume khi clone bắt đầu), và thêm âm thanh mưa nhẹ lặp lại (play sound until done) để cảnh mưa có cả tiếng lẫn hình

A2 Tuyết rơi clone chậm ❄️

Em dựng cảnh mùa đông đầu tiên trong project của mình — làm tuyết rơi chậm: clone bông tuyết (❄️) rơi từ trên xuống chậm hơn mưa. Backdrop đêm hoặc mùa đông.

Yêu cầu

  • Clone liên tục với wait 0.8 secs
  • Clone rơi chậm (change y by -2 hoặc -3)
  • delete this clone khi chạm đáy; bản gốc hide

✨ Thử thêm

Random kích thước mỗi bông (set size to pick random 30 to 80), và thêm hiệu ứng lắc nhẹ qua trái phải trong lúc rơi để trông tự nhiên hơn

B1 Bắn bong bóng 🎈

Em hóa thân thành người bán bong bóng ở công viên — điều khiển súng bong bóng ở dưới màn hình. Nhấn Space → bắn clone bong bóng bay lên. Chạm trần thì nổ!

Yêu cầu

  • Nhân vật di chuyển trái/phải
  • Space tạo clone bong bóng
  • Clone bay lên; chạm trên cùng → delete (hoặc hiệu ứng nổ)

✨ Thử thêm

Đếm số bong bóng bắn bằng biến số bong bóng, và cho bong bóng đổi màu ngẫu nhiên mỗi lần bắn (set color effect to pick random 0 to 200) để trông sặc sỡ như hội chợ

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
hide / ẩn bản gốc
when key space pressed / khi nhấn Space
create clone of myself / bắn 1 bong bóng
when I start as a clone / khi 1 bong bóng mới
show / hiện bong bóng
forever / lặp mãi
change y by 6 / bay lên
if <y > 170> then / nếu chạm trần
start sound Pop / phát tiếng nổ
delete this clone / xóa bong bóng

B2 Bắn sao Space clone bay lên 🚀

Em là phi công của một tàu vũ trụ nhỏ đang khám phá dải ngân hà — điều khiển tàu ở dưới màn hình. Nhấn Space → bắn clone sao bay lên. Sao chạm trần → biến mất kèm âm thanh.

Yêu cầu

  • Sprite tàu di chuyển trái/phải
  • Space → create clone of myself
  • Clone bay lên (change y by 8); chạm trên cùng (y > 170) → delete
  • Bản gốc hide

✨ Thử thêm

Biến số sao bắn — tăng mỗi lần Space, và giới hạn tốc độ bắn (thêm wait 0.2 secs sau mỗi lần tạo clone) để tránh bắn quá nhanh gây rối màn hình

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
hide / ẩn bản gốc (Rocket)
when key space pressed / khi nhấn Space
create clone of myself / bắn 1 sao
wait 0.2 seconds / giới hạn tốc độ bắn (thử thêm)
when I start as a clone / khi 1 sao mới
show / hiện sao
forever / lặp mãi
change y by 8 / bay lên
if <y > 170> then / nếu chạm trần

C1 Bắt sao rơi ⭐

Đêm nay trời đầy sao băng — em phải nhanh tay bắt được càng nhiều sao càng tốt! Sao clone rơi ngẫu nhiên, nhân vật điều khiển bắt sao gom điểm trong 30 giây. Hết giờ báo điểm!

Yêu cầu

  • Clone sao rơi; điều khiển 4 phím
  • Biến điểm; đếm ngược 30 giây
  • Hết giờ say điểm + stop all
  • Clone delete khi bắt hoặc chạm đáy

✨ Thử thêm

Sao rơi nhanh dần theo thời gian (tăng tốc độ change y), và thêm 1 loại "sao bạc" hiếm (random costume) đáng giá gấp đôi điểm để tạo động lực săn tìm

C2 Fruit catch nhiều loại điểm khác 🍎🍌

Em mở "vườn trái cây rơi" của riêng mình — clone táo 🍎 (+1 điểm), chuối 🍌 (+2 điểm), dưa hấu 🍉 (+3 điểm) — mỗi loại random costume khi clone bắt đầu. Bắt trong 30 giây!

Yêu cầu

  • Clone trái cây rơi liên tục; random costume (≥ 2 loại)
  • Chạm → change điểm theo loại (táo +1, chuối +2, dưa +3)
  • Biến điểm; đếm ngược 30 giây
  • delete this clone khi bắt hoặc chạm đáy

✨ Thử thêm

Thêm trái xấu 🍄 (-1 điểm khi bắt nhầm), và hiển thị bảng tổng kết cuối giờ liệt kê số lượng từng loại trái cây đã bắt (3 biến đếm riêng: số táo, số chuối, số dưa)

show / hiện trái cây
