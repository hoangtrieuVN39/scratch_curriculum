Đúng hay Sai?

Cô đọc từng câu, cả lớp giơ ngón cái lên (Đúng) hoặc xuống (Sai) — rồi click để xem đáp án ↓

1
"broadcast chỉ gửi tin cho 1 sprite duy nhất."
→ Sai — mọi sprite có when I receive cùng tên đều nhận được.
2
"Tên tin nhắn ở broadcast và when I receive phải giống hệt nhau."
→ Đúng.
3
"Game luôn chỉ có đúng 1 trạng thái duy nhất."
→ Sai — thường có Chờ, Đang chơi, Kết thúc (có khi thêm Đếm ngược).
4
"stop all chỉ dừng 1 sprite, các sprite khác vẫn chạy."
→ Sai — stop all dừng toàn bộ project.
5
"broadcast and wait chờ script nhận tin chạy xong mới chạy tiếp."
→ Đúng.

Nhớ lại Broadcast & trạng thái

Hôm nay em luyện lại broadcast và trạng thái game ngay tại lớp, rồi tự chọn 1 bài mở rộng để làm game có màn chờ, đếm ngược, thậm chí Pause và nhiều màn!
📡 🎮 ⏳ 🛑
📡 Broadcast broadcast gửi tin, when I receive nhận tin
🎮 Trạng thái game Chờ → Đang chơi → Kết thúc (có khi thêm Đếm ngược)
🛑 stop all Dừng toàn bộ script khi Game Over — nhiều sprite cùng nghe 1 tin!

LT1 Nút Play tự khóa ▶️🔒

Em luyện làm nút Play — nhưng lần này nút Play biết "tự khóa": ngay khi game bắt đầu chạy, nút tự ẩn đi để không ai bấm lại giữa ván, chỉ hiện lại khi bấm cờ xanh!

Yêu cầu

  • Sprite nút Play, click → broadcast start
  • Nhân vật ẩn/đứng yên khi chưa Start; when I receive start → hiện + di chuyển
  • Nút Play tự hide ngay khi nhận start, tự show lại khi bấm cờ xanh
🔄
Đổi máy 2 phút: kiểm tra chéo xem tên broadcast của bạn có gõ đúng và giống nhau ở cả hai đầu không.

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh (Nút Play)
show / hiện nút Play
when this sprite clicked / khi bấm Nút Play
broadcast start / phát tin bắt đầu
when I receive start / khi Nút Play nhận tin
hide / tự ẩn, khóa không cho bấm lại
when green flag clicked / khi bấm cờ xanh (Cat)
hide / ẩn Cat
when I receive start / khi Cat nhận tin
show / hiện Cat
forever / lặp mãi
move 5 steps / di chuyển
if on edge, bounce / chạm biên thì quay đầu

LT2 Game 4 trạng thái có đếm ngược 🎮⏳

Em luyện làm game có 4 trạng thái rõ ràng: Chờ → Đếm ngược ("3, 2, 1") → Đang chơi → Kết thúc — giống một trận thi đấu thật!

Yêu cầu

  • Biến trạng thái nhận 4 giá trị: chờ, đếm ngược, chơi, kết thúc
  • Nút Play → broadcast countdown → đếm "3,2,1" → broadcast start
  • Khi trạng thái = chơi: điều khiển + gom điểm
  • Thua → broadcast game over → set trạng thái to kết thúc
🩹
Đếm ngược không hiện? Kiểm tra say có đủ wait giữa mỗi số không.

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
set trạng thái to "chờ" / gán trạng thái = chờ
set điểm to 0 / gán điểm = 0
when this sprite clicked / khi bấm Nút Play
broadcast countdown / phát tin đếm ngược
set trạng thái to "đếm ngược" / gán trạng thái
when I receive countdown / khi nhận tin đếm ngược
say "3" for 1 secs / nói 3
say "2" for 1 secs / nói 2
say "1" for 1 secs / nói 1
broadcast start / phát tin bắt đầu
set trạng thái to "chơi" / gán trạng thái = chơi
when I receive start / khi nhận tin bắt đầu
forever / lặp mãi (điều khiển + gom điểm)

A1 Nút Start đếm ngược ▶️⏳

Mọi game hay đều cần một "cánh cửa mở màn" ấn tượng — em làm màn hình chờ đẹp: backdrop menu, nút START to, click → không bắt đầu ngay mà đếm ngược "3... 2... 1..." rồi mới thật sự vào game, giống các trận đấu thể thao thực thụ!

Yêu cầu

  • Backdrop menu; sprite nút START
  • Click → broadcast countdown → say "3","2","1" → broadcast start
  • Nhân vật chờ đến khi nhận start

✨ Thử thêm

Thêm âm thanh "tíc" mỗi số đếm ngược, và thêm hiệu ứng chữ số phóng to/thu nhỏ mỗi lần đổi để màn chờ sống động hơn

Gợi ý khối lệnh

when this sprite clicked / khi bấm nút START
broadcast countdown / phát tin đếm ngược
when I receive countdown / khi nhận tin đếm ngược
say "3" for 1 secs / nói 3
say "2" for 1 secs / nói 2
say "1" for 1 secs / nói 1
broadcast start / phát tin bắt đầu

A2 Pause có giới hạn lượt ⏸️🎟️

Có lúc đang chơi giữa chừng thì cần tạm dừng — nhưng để giữ trận đấu công bằng, em chỉ được Pause tối đa 3 lần mỗi ván! Hết 3 lượt thì nút Pause không còn tác dụng.

Yêu cầu

  • Nút Start + nút Pause; broadcast pause và broadcast resume
  • Biến số lần pause (bắt đầu = 0, +1 mỗi lần Pause)
  • Đủ 3 lần → nút Pause không broadcast nữa, say "Hết lượt pause!"

✨ Thử thêm

Khi Pause, backdrop đổi màu xám (change color effect), và hiển thị biến số lần pause trên Stage như "còn 2/3 lượt"

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
set số lần pause to 0 / gán số lần pause = 0
when this sprite clicked / khi bấm nút PAUSE
if <số lần pause < 3> then / nếu còn lượt
change số lần pause by 1 / tăng số lần pause
broadcast pause / phát tin tạm dừng
else / hết lượt rồi
say "Hết lượt pause!" / báo hết lượt
when I receive pause / khi nhân vật nhận tin
stop other scripts in sprite / dừng script di chuyển

B1 Game 3 màn, màn cuối kết hợp cả hai 🎯

Em thiết kế một hành trình phiêu lưu 3 chặng: màn 1 bắt sao, màn 2 né địch, và màn 3 phải làm CẢ HAI cùng lúc — giống màn boss cuối trong một trò chơi thực thụ!

Yêu cầu

  • Đúng 3 backdrop/màn; broadcast chuyển màn
  • Màn 1 = bắt sao; Màn 2 = né địch
  • Màn 3 = kết hợp cả bắt sao và né địch cùng lúc

✨ Thử thêm

Hiển thị biến màn hiện tại trên Stage, và thêm màn hình "Chúc mừng qua màn!" mỗi khi chuyển màn

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
forever / lặp mãi (Màn 1)
if <điểm = 5> then / nếu đủ 5 sao
broadcast màn 2 / phát tin sang màn 2
when I receive màn 2 / khi vào màn 2
switch backdrop to Màn 2 / đổi backdrop
(né địch 15 giây rồi broadcast màn 3)
when I receive màn 3 / khi vào màn 3
switch backdrop to Màn 3 / đổi backdrop
(sao và địch cùng xuất hiện)

B2 Level up nhân tốc độ 🆙

Game của em tự "lên level" khi người chơi đủ giỏi: đủ 10 điểm → broadcast level up → tốc độ địch = tốc độ gốc × level (level 2 nhanh gấp đôi, level 3 gấp ba!) — nhưng dừng lại ở level 3.

Yêu cầu

  • Biến điểm, level, tốc độ gốc
  • if điểm >= 10 and level < 3 → broadcast level up
  • when I receive level up → change level by 1 → set tốc độ địch to (tốc độ gốc × level) + reset điểm
  • Đạt level 3 → say "Em là bậc thầy!" và dừng tăng

✨ Thử thêm

Level 3: thêm 1 sprite địch di chuyển ngang thứ hai để tăng độ khó thực sự, không chỉ tăng tốc độ

Gợi ý khối lệnh

when green flag clicked / khi bấm cờ xanh
set level to 1 / gán level = 1
set tốc độ gốc to 3 / gán tốc độ gốc = 3
forever / lặp mãi
if <điểm >= 10> and <level < 3> then / nếu đủ điểm và chưa max level
broadcast level up / phát tin lên level
set điểm to 0 / reset điểm
when I receive level up / khi nhận tin lên level
change level by 1 / tăng level
set tốc độ địch to (tốc độ gốc × level) / cập nhật tốc độ
if <level = 3> then / nếu đạt max
say "Em là bậc thầy!" / khen thưởng

C1 Game có mạng + bất tử ngắn ❤️✨

Không phải lúc nào cũng "chết" ngay lần va chạm đầu! Chạm địch → mất 1 mạng + có 1 giây bất tử (nhấp nháy, không tính va chạm) để không bị mất liền 2-3 mạng cùng lúc.

Yêu cầu

  • Biến mạng (bắt đầu = 3); có nút Start
  • Chạm địch → change mạng by -1 + ghost effect + 1 giây bất tử
  • Trong lúc bất tử, không kiểm tra va chạm; if mạng = 0 → broadcast game over

✨ Thử thêm

Đổi hiệu ứng bất tử thành nhấp nháy liên tục (đổi ghost effect qua lại) thay vì mờ đứng yên, để nhìn rõ hơn là nhân vật đang bất tử

Gợi ý khối lệnh

when I receive start / khi nhận tin bắt đầu
set mạng to 3 / gán mạng = 3
set bất tử to 0 / gán bất tử = 0 (0 = không, 1 = có)
forever / lặp mãi
if <touching Địch?> and <bất tử = 0> then / nếu chạm địch và chưa bất tử
change mạng by -1 / trừ 1 mạng
set bất tử to 1 / bật bất tử
set ghost effect to 50 / nhấp nháy mờ
wait 1 seconds / chờ 1 giây bất tử
set ghost effect to 0 / trở lại bình thường
set bất tử to 0 / tắt bất tử
if <mạng = 0> then / nếu hết mạng
broadcast game over / phát tin thua

C2 Hai người chơi, điểm chung và riêng 👫📊

Rủ bạn cùng bàn chơi chung! 2 sprite — người 1 dùng phím mũi tên, người 2 dùng W A S D. Cả hai cùng bắt sao và chung biến điểm — nhưng mỗi người còn có điểm riêng để biết ai đóng góp nhiều hơn!

Yêu cầu

  • 2 sprite điều khiển khác nhau; biến điểm (For all sprites)
  • Biến điểm P1 và điểm P2 riêng cho từng người
  • Chạm sao → +1 điểm chung và +1 điểm riêng của người đó
  • Có nút Start; hết 30 giây → say tổng điểm chung + điểm riêng

✨ Thử thêm

Hiển thị say tên người bắt được sao cuối cùng, và thêm 1 "sao vàng" hiếm +3 điểm để tạo thời điểm gay cấn tranh giành

Gợi ý khối lệnh

when I receive start / khi nhận tin bắt đầu
set điểm to 0 / gán điểm chung = 0
set điểm P1 to 0 / gán điểm P1 = 0
set điểm P2 to 0 / gán điểm P2 = 0
forever / lặp mãi (đặt trên Sao)
if <touching Cat?> then / nếu chạm người chơi 1
change điểm by 1 / tăng điểm chung
change điểm P1 by 1 / tăng điểm P1
if <touching Dog?> then / nếu chạm người chơi 2
change điểm by 1 / tăng điểm chung
change điểm P2 by 1 / tăng điểm P2
say join "Chung: " điểm / báo tổng điểm cuối trận
