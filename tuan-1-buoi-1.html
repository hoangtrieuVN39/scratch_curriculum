Em sẽ làm được gì sau khóa học? What will you be able to do after this course?

Khóa học 4 tháng (16 tuần, 32 buổi) — em từng bước làm quen lập trình và cuối khóa tự thiết kế game riêng! A 4-month course (16 weeks, 32 sessions) — you'll learn coding step by step and design your own game by the end!
  • Dùng thành thạo Scratch: Stage, Sprite, Backdrop, khối lệnh Master Scratch: Stage, Sprites, Backdrops and code blocks
  • Cho nhân vật di chuyển, đổi hình, nói chuyện và phản ứng khi bấm phím Make characters move, change costumes, talk and react to key presses
  • Thêm âm thanh, quiz tương tác và nhiều nhân vật cùng lúc Add sounds, interactive quizzes and many characters at once
  • Dùng vòng lặp, điều kiện, biến để làm game có điểm số Use loops, conditions and variables to build games with scores
  • Dùng broadcast, clone và My Blocks để code gọn hơn Use broadcast, clones and My Blocks to keep your code tidy
  • Tự làm và hoàn thiện một game theo ý thích Create and polish your own game
  • Thuyết trình game trước lớp 2–3 phút Present your game to the class in 2–3 minutes

Mục tiêu

Hôm nay em học gì?

Em biết lập trình là gì, nhận biết Stage, Sprite, Backdrop, khối lệnh và bấm cờ xanh để chạy chương trình đầu tiên.
🎭 🐱 🧱 ▶️
  • Hiểu Scratch giống sân khấu kịch — sprite là diễn viên, khối lệnh là kịch bản
  • Nhận biết giao diện: Stage, Sprite, Backdrop, khối lệnh
  • Ghép khối when green flag clicked và move
  • Chạy thử chương trình bằng cờ xanh
Kiến thức mới

6 từ quan trọng hôm nay

💻 Lập trình Ra lệnh cho máy tính làm từng việc theo thứ tự.
🎭 Stage Sân khấu — nơi nhân vật biểu diễn.
🐱 Sprite Nhân vật trên sân khấu.
🖼️ Backdrop Phông nền phía sau sân khấu.
🧱 Khối lệnh Mảnh lego — ghép lại thành chương trình.
▶️ Cờ xanh Nút "Bắt đầu!" — chạy chương trình.
💡 Ẩn dụ: Sprite = diễn viên · Khối lệnh = kịch bản · Cờ xanh = hiệu lệnh mở màn!

  • Mèo di chuyển tổng cộng 30 bước
  • Chương trình chạy được

  • Tổng cộng khoảng 30 bước
🙋 Xong TH1? Giơ tay cho thầy biết!
Tiếp theo: TH2 — đổi cảnh mới.
Thực hành

TH2 Đổi cảnh mới 🌄

Đổi phông nền, đổi nhân vật và đặt tên riêng cho sprite.

Yêu cầu

  • Backdrop khác backdrop mặc định
  • Sprite khác mèo mặc định (hoặc chỉnh mèo)
  • Sprite có tên riêng (không để "Sprite1")

Gợi ý từng bước

  1. Góc dưới phải → Choose a Backdrop → chọn cảnh em thích
  2. Choose a Sprite → chọn nhân vật (Dog, Bear, Unicorn…)
  3. Click ô tên sprite → gõ tên mới (vd. Luna, Robot)
Thực hành

TH2 Checklist tự kiểm

  • Backdrop đã đổi
  • Sprite đã đổi hoặc chỉnh sửa
  • Có tên riêng cho sprite

💡 Gợi ý sáng tạo

  • Chọn backdrop theo chủ đề em thích
  • Đặt tên sprite theo nhân vật trong truyện
  • Thử tab Costumes — tô màu sprite

BTVN1 Lưu project đầu tiên 💾

Lưu project Scratch về máy với tên của em.

Yêu cầu

  • File đuôi .sb3
  • Tên file: scratch-[tên em] (vd. scratch-Minh)
  • Mở lại file được
  • Đã lưu file .sb3
  • Tên file đúng quy tắc
  • Mở lại được, project còn nguyên

Gợi ý từng bước

  1. File → Save to your computer
  2. Chọn thư mục (Desktop hoặc Documents)
  3. Đặt tên scratch-[tên em] → Save
  4. Mở lại file để kiểm tra
