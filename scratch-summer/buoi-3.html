New knowledge (15 min)

The 3 pieces of every catching game

📦 Variable — a memory box Create Score in the Variables group. The block change Score by 1 adds 1 to the box.
🎲 pick random pick random -240 to 240 — run it 5 times, get 5 different numbers. That's why the bánh mì falls where no one expects.
🔁 forever + if touching The computer checks "touching yet?" non-stop — the moment it hits the basket, the score goes up. That IS the game rule.
💡 The catching-game formula: 1 score variable + items falling at random spots + a touch rule. Fruit Ninja and every egg-catching game use exactly this.
🤔 Predict: change Score by 1 adds a point. So what does change Score by -2 do? We'll need it very soon… 🍈

A score box + a random number machine 🎲

Random — different every single run:

Level up · 🟡 Normal

NORMAL 🍈 Durian from the sky

Not everything falling from the sky should be caught! Durian is spiky — catch it and it's −2 points. Players must learn to dodge.

Requirements

  • A separate durian sprite that falls like the bánh mì
  • Catch it → change Score by -2
  • An "ouch!" sound when the durian lands in your basket

Level up · 🔴 Hard

HARD ⏱️ 60-second rush

Pick 1 of the 2 mechanics (finished early? do the other one too):

Option A — The 60-second clock

  • Variable Timer starts at 60
  • Goes down by 1 every second
  • Time's up → stop the game + show the final score
when green flag clicked
set [Timer] to 60 — the 60-second clock
repeat until [Timer = 0]
wait 1 seconds
change [Timer] by -1 — one second gone
say (join "Your score:" (Score)) — show off the final score
stop [all] — end the whole game

Option B — Falling faster as you score

  • Variable Speed starts at −5
  • The bánh mì falls with change y by Speed
  • Every catch → Speed creeps up — the better you play, the faster it falls
set [Speed] to -5 — starting speed (on green flag)
repeat until touching [Basket]
change y by (Speed) — fall at the current speed
change [Speed] by -0.2 — a bit faster next drop
