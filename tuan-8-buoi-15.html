Mục tiêu

Hôm nay em học gì?

Em học if / else (nếu thì / không thì) để Scratch quyết định làm gì, và biến (variable) để lưu số như điểm số trong game!
🔀 📊 ⭐ 🎮
  • if ... then / if ... else — quyết định theo điều kiện
  • Biến — hộp nhớ lưu 1 con số (điểm, mạng...)
  • touching — kiểm tra chạm sprite khác
  • Hiển thị biến trên Stage như bảng điểm thật
Kiến thức mới (20 phút)

if/else & Biến 📊

🔀 if ... then Nếu đúng → chạy khối bên trong (nhóm Control).
🔀 if ... else Đúng → nhánh trên; sai → nhánh else.
👆 touching [sprite]? Kiểm tra có chạm nhân vật khác không (nhóm Sensing).
📊 Biến (Variable) Hộp nhớ lưu 1 số: set điểm to 0 (gán) · change điểm by 1 (tăng) · ô tròn điểm (đọc giá trị).
👁️ Hiển thị biến trên Stage Tick ô nhỏ cạnh tên biến trong Variables → số hiện góc Stage như bảng điểm thật.
Vì sao quan trọng? Biến giúp Scratch ghi nhớ một con số xuyên suốt cả ván chơi. Kết hợp với if/else, Scratch có thể quyết định dựa trên số đó — đủ điểm thì thắng, hết mạng thì thua. Đây là hai mảnh ghép cuối cùng để em làm được một game hoàn chỉnh có luật chơi!
Ví dụ mẫu 1

Đếm click 🔢

Ghép các khối sau — mỗi lần click sprite, số tăng lên:

when green flag clicked / khi bấm cờ xanh
set số lần click to 0 / gán số lần click = 0
when this sprite clicked / khi bấm vào sprite
change số lần click by 1 / tăng số lần click

🔍 Quan sát

  • Biến chỉ "nhớ" số, chưa tự quyết định gì
  • set chạy 1 lần lúc bắt đầu (reset về 0)
  • change chạy mỗi lần click (cộng dồn)

✏️ Thử ngay

  • Tạo biến số lần click
  • Bấm cờ xanh, click sprite nhiều lần
  • Xem số trên Stage tăng dần 🔢
Ví dụ mẫu 2

If/else theo số lần click 🗣️

Cùng biến đó, nhưng lần này dùng để quyết định sprite nói gì:

when this sprite clicked / khi bấm vào sprite
if <số lần click > 5> then / nếu số lần click hơn 5
say "Em click giỏi quá!" / khen ngợi
else / còn chưa đủ thì
say "Click thêm nữa!" / nhắc click thêm

Biến + if/else phối hợp với nhau chính là công thức làm game!

🤔 Em đoán xem?

Nếu biến số lần click đang là 3 và em click thêm 2 lần nữa (tổng thành 5), sprite sẽ nói nhánh nào — "giỏi quá" hay "click thêm"?

Đoán trước, rồi thử trên Scratch để kiểm tra!

Thực hành

TH1 Né quái đuổi, ăn sao ⭐👹💨

Quái vật lần này không đứng yên — nó di chuyển qua lại liên tục, và càng sống sót lâu thì càng đi nhanh hơn! Chạm sao được thưởng; chạm quái mất mạng.

Yêu cầu

  • Có 3 sprite: nhân vật (điều khiển phím mũi tên), Sao, Quái vật
  • Quái vật di chuyển qua lại liên tục (forever + move + if on edge, bounce)
  • Biến tốc độ quái tăng +1 sau mỗi 10 giây sống sót
  • Biến mạng = 3 khi cờ xanh; biến giây sống đếm thời gian sống
  • if touching Monster → change mạng by -1; if mạng = 0 → báo thua kèm số giây sống

Gợi ý từng bước

when green flag clicked / khi bấm cờ xanh (Quái vật)
set tốc độ quái to 2 / gán tốc độ quái = 2
forever / lặp mãi
move tốc độ quái steps / di chuyển theo tốc độ
if on edge, bounce / chạm biên thì quay đầu
forever (script riêng) / mỗi 10 giây: change tốc độ quái by 1
when green flag clicked / khi bấm cờ xanh (Cat)
set mạng to 3 / gán mạng = 3
set giây sống to 0 / gán giây sống = 0
forever / lặp mãi
if <touching Star?> then / nếu chạm sao
start sound Collect / phát tiếng nhặt
go to random position / sao đổi chỗ
if <touching Monster?> then / nếu chạm quái vật
change mạng by -1 / trừ 1 mạng
wait 1 seconds / chờ tránh trừ liên tục
if <mạng = 0> then / nếu hết mạng
say join "Hết mạng rồi! Sống " giây sống " giây!" / báo thua
stop this script / dừng lại

TH2 Đua với thời gian 🏆⏳

Không chỉ đếm điểm — giờ có thêm đồng hồ đếm ngược 20 giây! Đủ 10 điểm trước khi hết giờ thì thắng; hết giờ hoặc hết mạng (từ TH1) thì thua.

Yêu cầu

  • Biến điểm hiển thị Stage, set = 0 khi cờ xanh
  • Biến giây còn lại = 20, đếm ngược mỗi giây
  • Chạm sao: change điểm by 1; đủ 10 → say thắng + stop all
  • Hết giờ chưa đủ điểm, hoặc mạng (từ TH1) = 0 → say thua + stop all

Gợi ý từng bước

when green flag clicked / khi bấm cờ xanh
set điểm to 0 / gán điểm = 0
set giây còn lại to 20 / gán giây còn lại = 20
forever / lặp mãi (đếm ngược)
wait 1 seconds / chờ 1 giây
change giây còn lại by -1 / giảm giây còn lại
if <giây còn lại = 0> and <điểm < 10> then / hết giờ chưa đủ điểm
say "Hết giờ! Thua rồi." / báo thua
stop all / dừng toàn bộ
forever / lặp mãi (đặt trên sprite Star)
if <touching Cat?> then / nếu chạm nhân vật
change điểm by 1 / tăng điểm
if <điểm = 10> then / nếu đủ 10 điểm
say "Em thắng rồi!" / báo thắng
stop all / dừng toàn bộ
if <mạng = 0> then / nếu hết mạng (từ TH1)
say "Thua rồi!" / báo thua
stop all / dừng toàn bộ

✨ Thử thêm

Giảm còn 15 giây hoặc tăng ngưỡng thắng lên 15 điểm để khó hơn nữa; thêm đếm ngược "3, 2, 1" bằng say trước khi bắt đầu chơi.

Mẹo nhỏ

Gặp khó? Thử mẹo này!

🔄
Điểm không reset?
Luôn set điểm to 0 khi cờ xanh — không reset thì điểm cũ còn từ lần chơi trước!
🔀
Khi nào dùng else?
if ... else giúp game có hai nhánh rõ ràng (đúng/sai, thắng/thua).
👆
touching không nhận ra?
Code if touching nên nằm trong forever để kiểm tra liên tục.
➕
Mất nhiều mạng cùng lúc?
Thêm wait 1 seconds sau khi trừ mạng để tránh trừ liên tục nhiều lần trong 1 giây!
Ôn tập

Câu hỏi ôn — Em trả lời nhé!

Cô click để xem đáp án gợi ý ↓

1
Biến dùng để làm gì? Cho ví dụ trong game.
→ Biến là hộp nhớ lưu 1 con số xuyên suốt ván chơi — ví dụ điểm, mạng.
2
set và change khác nhau thế nào?
→ set gán 1 giá trị cố định (thường để reset); change cộng thêm/bớt vào giá trị hiện tại.
3
if ... else dùng khi nào?
→ Khi cần 2 nhánh rõ ràng: đúng làm việc này, sai làm việc khác (ví dụ thắng/thua).
4
Làm sao hiển thị điểm trên màn hình Stage?
→ Tick ô nhỏ cạnh tên biến trong mục Variables.
5
Tại sao if touching thường đặt trong forever?
→ Vì Scratch cần kiểm tra điều kiện đó liên tục, không phải chỉ 1 lần.
🙋 Mời 1–2 em chiếu màn hình project TH2 "Đua với thời gian" của mình!
🔀

Tổng kết buổi học

  • ✅ if ... then = làm khi đúng điều kiện
  • ✅ if ... else = 2 nhánh đúng/sai
  • ✅ Biến = hộp nhớ lưu số (set / change)
  • ✅ touching = kiểm tra chạm sprite khác
  • ✅ Biến + if/else = công thức làm game có luật chơi
